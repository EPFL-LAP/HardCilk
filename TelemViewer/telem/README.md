# TelemViewer application

The complete installation, build, deployment, and startup instructions are in [`../README.md`](../README.md).

Useful commands from this directory:

```bash
pnpm install --frozen-lockfile  # download pinned JavaScript dependencies
pnpm build                      # build native decoder and frontend
pnpm start                      # serve production build and telemetry API
pnpm dev                        # development server with hot reload
pnpm lint                       # run ESLint
```
